# NO.15（ナンバー・バトル15）

最大16人がスマートフォンで参加する、GitHub Pages + Firebase の数字カードゲームです。

**最初に `README.html` をダブルクリックして開いてください。**

- 初期設定・GitHub Pages公開・教員と生徒の操作・ルール・CSVの説明を1冊にまとめています。
- Firebaseの設定コードから `config.js` を作る補助ツールも説明書に含めています。
- `demo.html` は設定不要で動く体験版です。教員／生徒の画面を切り替えられます。別端末とは同期しません。
- オンライン対戦は `index.html` をGitHub Pagesで公開し、Firebase設定後に使います。
- ZIP内の**ファイルとフォルダーをそのままリポジトリの直下へ**アップロードします。`index.html` が直下になるようにしてください。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` / `styles.css` | 本番の画面・デザイン |
| `app.js` / `view.js` | 画面操作・表示 |
| `backend.js` | Firebase同期・進行・体験モード |
| `core.js` | 得点計算・ラウンド管理・CSV |
| `config.js` | 自分のFirebase Web用接続設定に置換 |
| `database.rules.json` | Realtime Databaseへ公開するアクセスルール |
| `firebase.json` | 開発者向けローカル検証設定 |
| `vendor/` | 同梱のQRコード生成ライブラリとライセンス |
| `README.html` | 初期設定・公開・操作・ゲームルール |
| `TESTING.md` | 確認結果・未確認事項・再検証方法 |
| `tests/` / `package*.json` | 自動テストと、その開発用依存関係 |
| `demo.html` | 本番コードから生成した1ファイルの体験版 |
| `build-demo.mjs` | 体験版を再生成する開発者向け補助スクリプト |

本番公開にnpmやビルド操作は不要です。`node_modules` をアップロードする必要はありません。

## 設計上の前提

- 教員はGoogleログイン、生徒はFirebase匿名認証を使います。
- 教員のブラウザーが参加受付・提出人数同期・自動集計を担当します。教員画面をオンラインで開いたまま利用します。
- 教員が切断しても、Firebaseに保存済みの提出は残ります。再接続後に進行を再開します。
- 未発表カードは公開状態と別の領域に保存し、他の生徒によるDBからの読み取りも拒否します。
- ランキング非公開は画面表示の制御です。公開ログの計算から得点を再現することまでは防ぎません。
- 匿名認証はブラウザー単位です。別端末の同一人物の二重登録は教員の確認で管理します。端末変更時は教員が本人確認後に引き継ぎます。
- ルームデータは教員が削除するまで保持します。必要な結果はCSVで保存してください。

## 開発者向けテスト

Node.js 24以上・Java 21以上を推奨します。初回のみ `npm ci`、その後 `npm test`、`npm run test:rules` を実行します。テストはローカルの `demo-no15` プロジェクトを使い、実際のFirebaseへデータを書き込みません。

Firebase SDKは12.4.0に固定し、公式CDNから必要な時に読み込みます。体験版は外部通信なしで動きます。
